💡 About This Project

Project Objective

To explore student performance using study hours, attendance, assignment scores and exam marks.

Technologies Used

Python, Pandas, Matplotlib, Seaborn, Scikit-learn, HTML, CSS and JavaScript.

Learning Outcomes

Data analysis, data visualization, introductory machine learning and responsive web design.

This demonstration uses 10 sample records. Results are not validated real-world academic predictions.
